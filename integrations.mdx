## Setting Up Webhooks

Webhooks enable real-time notifications for events like page publishes or comments.

<Steps>
  <Step title="Create Webhook" icon="plus">
    Navigate to `https://dashboard.example.com/settings/webhooks` and click "New Webhook".
  </Step>
  <Step title="Configure Events" icon="settings">
    Select events such as `page.updated` or `comment.added`.
  </Step>
  <Step title="Add Endpoint" icon="link">
    Enter your webhook URL, e.g., `https://your-webhook-url.com/webhook`.
  </Step>
  <Step title="Test and Save" icon="check-circle">
    Send a test payload and save the configuration.
  </Step>
</Steps>

Here is an example webhook payload:

<CodeGroup tabs="JSON">
  ```json
  {
    "event": "page.updated",
    "data": {
      "pageId": "doc_123abc",
      "title": "API Reference",
      "url": "https://docs.example.com/api"
    },
    "timestamp": "2024-10-15T10:30:00Z"
  }
  ```
</CodeGroup>

<Callout kind="tip">
  Use secret tokens to verify webhook authenticity. Compare `X-Areeba-Signature` header with HMAC SHA256 of the payload.
</Callout>

## API Access for Custom Extensions

Build custom integrations using the Areeba Osama API at `https://api.example.com`.

### Authentication

Use API keys for authentication.

<ParamField header="Authorization" param-type="string" required="true">
  Bearer `{YOUR_API_KEY}`.
</ParamField>

### List Integrations Endpoint

Fetch available integrations:

<Request tabs="cURL,JavaScript">
  ````bash
  curl -X GET https://api.example.com/v1/integrations \
    -H "Authorization: Bearer YOUR_API_KEY"
  ````

  ````javascript
  const response = await fetch('https://api.example.com/v1/integrations', {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  });
  const integrations = await response.json();
  ````
</Request>

<Response tabs="200">
  ```json
  {
    "integrations": [
      {
        "id": "slack",
        "name": "Slack",
        "enabled": true
      }
    ]
  }
  ```
</Response>

<Tabs>
  <Tab title="Node.js" icon="nodejs">
    ```javascript
    const axios = require('axios');
    axios.get('https://api.example.com/v1/integrations', {
      headers: { Authorization: `Bearer ${process.env.API_KEY}` }
    }).then(res => console.log(res.data));
    ```
  </Tab>
  <Tab title="Python" icon="python">
    ```python
    import requests
    response = requests.get(
      'https://api.example.com/v1/integrations',
      headers={'Authorization': f'Bearer {os.getenv("API_KEY")}'}
    )
    print(response.json())
    ```
  </Tab>
</Tabs>

## Exporting Documentation

Export your docs to various formats for sharing or migration.

<Expandable title="Supported Formats" default-open="true">
  - PDF: High-fidelity printable versions
  - Markdown: Raw source for GitHub or other platforms
  - HTML: Static sites for hosting
</Expandable>

Use the API to export:

```bash
curl -X POST https://api.example.com/v1/exports \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"format": "pdf", "pages": ["doc_123abc"]}'
```

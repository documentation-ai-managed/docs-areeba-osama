## Overview

Areeba Osama provides a centralized hub for your project documentation. You create, organize, and collaborate on docs without switching tools. This space handles Markdown, MDX, and rich components to build professional documentation sites quickly.

Use it to document APIs, user guides, or internal wikis. Start with templates and customize with your brand, like the primary color `#3B82F6`.

## Quick Start

Get up and running in minutes. Follow these steps to create your first documentation page.

<Steps>
  <Step title="Create Account" icon="user-plus">
    Sign up at `https://dashboard.example.com/signup` with your email.
  </Step>
  <Step title="New Space" icon="plus">
    Click "New Documentation Space" and name it "Areeba Osama".
  </Step>
  <Step title="Add Content" icon="edit-3">
    Create your first page using Markdown or MDX components.
  </Step>
  <Step title="Publish" icon="globe">
    Deploy to a custom domain or share the live site link.
  </Step>
</Steps>

## Brand Guidelines

<Callout kind="tip" style="--brand-color: #3B82F6;">
  Use the primary brand color `#3B82F6` for headings, buttons, and accents. Pair it with white text for optimal contrast. Avoid using it for backgrounds—reserve for interactive elements.
</Callout>
